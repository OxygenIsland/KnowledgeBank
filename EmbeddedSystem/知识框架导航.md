## 学习路径建议

### 入门路线（6-8周）
```
第1-2周：硬件基础 + C语言 → 完成《C语言基础》全文
第3-4周：GPIO + 时钟 + UART → 跑通"点灯+串口打印"实验
第5-6周：定时器 + PWM + 中断 → 实现PWM调光、外部中断
第7-8周：通信协议 + FreeRTOS → 移植Modbus + 多任务改造
```

### 进阶路线（8-12周）
```
第1-2周：Bootloader开发 → 掌握IAP升级流程
第3-4周：HardFault调试 → 系统性掌握故障定位
第5-6周：DMA高效编程 → 优化性能瓶颈
第7-8周：项目实战 → 综合运用所有知识完成小项目
```
