# 视频笔记总结

## 完整流程

处理用户提供的字幕文件或视频内容时，执行以下步骤：

### 1. 读取源内容

- **字幕文件**：直接读取完整文件内容
- **B 站视频**：使用 `bilibili-subtitle` skill 提取字幕后再处理

### 2. 分析内容结构

识别以下维度：
- **主题**：视频讲的是什么
- **受众**：入门/进阶/专家
- **章节**：视频有哪些主要段落
- **深度**：概念介绍 / 详细讲解 / 实战演示
- **是否有图**：视频是否有演示图表、流程图（决定是否留图片占位符）

### 3. 生成笔记

**目标文件**：在知识库 `{{KNOWLEDGE_BANK}}` 下找到对应分类目录，用中文标题命名 `.md` 文件。

**笔记结构规范：**

```
---
title: "[[文件标题]]"
type: Permanent
status: done
Creation Date: YYYY-MM-DD HH:MM
tags:
  - 标签1
  - 标签2
---

# 文件标题

## 概述（一段话总结核心内容）

## 主要内容章节1

详细笔记内容...

## 主要内容章节2

详细笔记内容...

...

## 参考资料
```

**写作要求：**

- 使用自己的话总结，不复制原文
- 核心概念加粗 `**加粗**`
- 要点使用无序列表
- 保留关键数据（数字、比例、金额、技术参数等）
- 遇到技术术语第一次出现时注明英文原文
- 如视频中有图解/流程图，在对应位置插入 `![描述](图片占位符-xxx.png)`，后续可补充图片
- 最后注明：`*笔记整理自视频转录，仅供学习参考。*`

**图片占位符命名规则：** `图片占位符-描述.png`，如 `图片占位符-STM32系统结构图.png`

### 4. 完善 frontmatter

自动填充：
- `title`：文件名
- `type`：Permanent
- `status`：done
- `Creation Date`：当天日期时间
- `tags`：根据内容推断 1~3 个标签

### 5. 追加而非覆盖

如果目标文件已存在，读取原文件后：
- 保留原有 frontmatter 和内容
- 在末尾追加新章节，或合并到对应章节
- 不删除原有内容
