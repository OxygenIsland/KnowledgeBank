## 常见视频类型的笔记侧重

| 类型 | 侧重 | 笔记深度 |
|------|------|---------|
| 概念入门 | 定义、历史、背景、术语解释 | 全面覆盖，重点清晰 |
| 实战教程 | 步骤、代码、配置、注意事项 | 步骤完整，代码完整 |
| 源码解析 | 架构、数据结构、核心逻辑 | 结构图 + 关键代码 |
| 产品评测 | 参数、对比、优缺点 | 参数表格 + 总结 |
| 行业分析 | 背景、趋势、关键数据 | 逻辑清晰，数据完整 |

## 图片占位符规范

当视频内容包含图表、流程图、界面截图时，在对应位置插入：

```markdown
![图片描述](图片占位符-唯一标识.png)
```

命名原则：
- 中文描述，简洁
- 唯一性：不与同一文件内其他占位符重复
- 示例：`图片占位符-STM32系统结构图.png`、`图片占位符-启动模式表.png`

## 字幕时间戳处理

- 字幕文件中的时间戳（如 `00:05`）**不写入笔记**
- 笔记中不使用时间引用
- 仅在视频有明显时间分节点时，可在章节标题旁注明（如 `## 第三章 系统结构`）

## 多集视频处理

如果字幕文件包含多集内容（如 `P2`、`P3`），每集生成独立笔记文件，命名加集数后缀：

```
STM32简介.md       # 第1集
STM32开发环境搭建.md  # 第2集
```

## 常见错误避免

1. **不过度总结**：不遗漏关键技术参数、配置方法
2. **不原文照搬**：用 Agent 自己的话重新组织内容
3. **不遗漏图表**：凡视频中出现图片的位置，都留占位符
4. **不覆盖已有笔记**：已存在的文件只追加不覆盖
